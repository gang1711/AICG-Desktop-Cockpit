# TagStudio 中文速查卡（界面已是简体中文）

> 重启 TagStudio 后生效。如果界面还是英文：菜单栏 **编辑(Edit) → 设置(Settings) → 语言(Language) → 简体中文**。
> 它是"原地索引"：只记标签不挪文件，删掉库文件也不伤素材。

## 一、第一次用（三步建库）

1. 双击 `F:\软件\TagStudio\TagStudio.exe`
2. 首页大按钮 **打开/创建库 (Ctrl+O)** → 选一个文件夹（推荐 `<工作台>\素材中心`，要管剧组资产就选你的剧组目录）
3. 保存后左侧 **添加文件夹** 把子目录勾进来 → 它自动扫描生成缩略图

库文件是文件夹里的一个 `.ts` 文件——**偶尔复制一份就是备份**。

## 二、建标签体系（建议四类起步）

菜单/侧栏 **标签(Tags) → 新建标签**，先建四个"父标签"：

| 父标签 | 子标签示例 |
|:---|:---|
| 角色 | 主角、女主、反派、师父（用你项目的角色名） |
| 场景 | 宗门大殿、雨夜街市、山林、云海 |
| 情绪/氛围 | 热血、悲伤、悬疑、燃、治愈 |
| 项目 | 我的漫剧E01、我的漫剧E02 |

## 三、日常三动作

- **打标签**：选中图片/音频/视频 → 右侧 **添加标签** → 点选即可（一个文件多标签）
- **检索**：顶部搜索框输入标签名 → 秒出所有命中素材（这就是"捞所有雨夜场景图"的玩法）
- **预览**：网格里单击，右侧详情直接播放音频/视频

## 四、和现有工作流的分工

| 找素材方式 | 用什么 |
|:---|:---|
| 记得标签（"那批燃向BGM"） | TagStudio |
| 记得文件名（"主角 三视图"） | Everything / DeskBox 搜索 |
| 只想快速看一眼 | QuickLook 空格预览 |
| 成体系的生产资产 | AICG production 的 S 级资产库（已有，别重复建） |
