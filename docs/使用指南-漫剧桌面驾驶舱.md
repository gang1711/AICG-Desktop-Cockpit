# 漫剧创作桌面驾驶舱 · 使用指南（开源通用版）

> DeskBox 格子驾驶舱 + Listen1 聚合音乐 + Lively 壁纸可视化 + TagStudio 素材标签 + QuickLook/Everything + TranslucentTB 沉浸任务栏 + 知识中枢。
> 本指南为公开通用版；部署后各路径以脚本输出为准。

---

## 一、你得到了什么

| 模块 | 角色 |
|:---|:---|
| DeskBox（16 格） | 桌面格子驾驶舱：收纳格+映射格+待办/随记/时光/天气/音乐 |
| Listen1 | 网易云/QQ/酷狗/酷我/B站/咪咕 聚合搜索播放 |
| Lively Wallpaper | 壁纸轮换 + 视频壁纸 + 音频可视化（Fluids/Music TV/Music Tunnel） |
| TagStudio（简体中文） | 图片/视频/音频标签管理，原地索引 |
| QuickLook | 空格即时预览 |
| Everything | 全盘秒搜（并入 DeskBox 搜索） |
| TranslucentTB | 任务栏全透明沉浸 |
| 知识中枢 | 技能/提示词/方法论/理论/书籍/教学视频 自动归库（见下文） |

## 四、知识中枢：拖进去就自动归位

- **自动分类**：按扩展名 + 文件名/内容关键词，归入提示词/技能/方法论/底层理论/书籍教材/教学视频/图片参考
- **自动中文名**：从内容首行标题提取中文名（索引记录原始路径，全程可溯）
- **自动去重**：SHA-256 完全相同跳过；同类目标题近似（≥92%）疑似重复跳过
- **大文件不复制**：>20MB（教学视频等）生成指针卡记录原路径
- **技能不搬运**：主系统已注入的技能生成 [已注入] 指针卡；全盘收割的散装技能标 [待整理]，`promote` 一条命令注入

```powershell
python 知识中枢.py scan               # 处理收件箱（看护每5分钟自动做）
python 知识中枢.py harvest            # 全盘收割技能/提示词/教程/书籍（可反复续跑）
python 知识中枢.py promote 3          # 注入第 3 条待整理技能到主系统
python 知识中枢.py report             # 统计
python 知识中枢.py dedupe --delete    # 清理重复
```

配置 `知识中枢\config.json`：注入目标目录、收割磁盘、排除目录/扩展名、复制阈值，全部可改。

## 五、日常漫剧工作流

```
灵感/素材 → 待处理 → 每日5分钟分类 → 剧组项目 / 素材中心 / 知识中枢
听歌定节奏 → Listen1 搜索播放 → DeskBox 音乐胶囊遥控 → 满屏可视化找节奏
生成新图 → 扔壁纸库\静态 → 每小时自动上墙 → 壁纸即作品橱窗
待办五色 = 制作阶段：🔵剧本 🟣分镜 🟠生成 🟢审核 🔴发布
```

## 六、效率技巧

1. Ctrl+Alt+D 显隐全部格子（录屏/演示/专注三态）
2. 空格预览分镜图/视频（QuickLook）
3. 搜索框一个框搜全盘文件+随记+待办（Everything 已并入）
4. 待办颜色=阶段，一屏看清瓶颈
5. 胶囊悬停展开，不占空间
6. 收件箱是唯一的"随手丢"区——其它区域永远整洁
7. 每周复盘：没打开的格子删掉、太挤的格子开自动叠放（脚本默认已开）
8. 共享屏幕前 Ctrl+Alt+D 一键清桌面

## 七、注意事项

- Listen1 聚合音乐仅限个人试听；发布漫剧必须用可商用 BGM
- TagStudio 是 Alpha，库文件（.ts）定期复制备份
- 待办弹窗提醒依赖 Windows 通知权限；格子内视图不受影响
- 时光格氛围板需在 UI 里授权一次：右键时光格 → 背景设置 → 本地文件夹 → 选壁纸库\静态
- 桌面图标可右键桌面 → 查看 → 取消显示（文件都在格子和工具里）
